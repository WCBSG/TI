# 八路红外循迹模块 (IRPHOTO)

> 对应代码：`OurProject/project/mdk/IRPHOTO.c` / `IRPHOTO.h`

## 硬件原理

8 个红外光电管（IR LED + 光电三极管）并排安装于车底，朝向赛道地面。白色赛道反射红外光，黑色边线吸收红外光。传感器输出数字信号：**黑线=1，白底=0**。

```
  传感器排列 (俯视，车头朝上)
  ┌──┬──┬──┬──┬──┬──┬──┬──┐
  │ 1│ 2│ 3│ 4│ 5│ 6│ 7│ 8│
  └──┴──┴──┴──┴──┴──┴──┴──┘
  左←                        →右
```

8 路传感器覆盖宽度约 12~16cm，足以覆盖 1.8cm 宽的赛道边线。

## API

```c
// 计算巡线偏差
int calc_error(int s[8]);

// 检测停车标志 / 冲出赛道
int is_stop(int s[8]);
```

### `calc_error` — 加权偏差计算

```c
int calc_error(int s[8])
{
    int error = 0;
    int weight[8] = { -7, -5, -3, -1, 1, 3, 5, 7 };
    for (int i = 0; i < 8; i++) {
        if (s[i] == 1)
            error += weight[i];
    }
    return error;
}
```

| 返回值 | 含义 |
|--------|------|
| `error > 0` | 黑线偏右，车需右转 |
| `error < 0` | 黑线偏左，车需左转 |
| `error = 0` | 黑线居中（理想状态） |
| `error = 0` (全白) | 未检测到线（按上一个有效值保持） |

**权重设计**：两侧权重大（±7），中间权重小（±1），使小车对偏离中心更敏感。

**典型场景**：

| 传感器状态 | 偏差 | 说明 |
|------------|------|------|
| `00111100` | 0 | 线居正中，4个传感器看到黑线 |
| `00011110` | +4 | 线偏右 (1+3+5-7=-5..wait) |
| `01110000` | -4 | 线偏左 |
| `00000011` | +12 | 急弯，线在最右侧 |

### `is_stop` — 停车标志检测

```c
int is_stop(int s[8])
{
    int count = 0;
    for (int i = 0; i < 8; i++) {
        if (s[i] == 1) {
            count++;
            if (count >= 3)         // ≥3 个连续传感器检测到黑线
                return 1;           // → 停车标志（垂直黑线）
        } else {
            count = 0;              // 不连续则重置计数
        }
    }
    return 0;
}
```

| 返回值 | 含义 |
|--------|------|
| `1` | 停车（≥3 个连续传感器看到黑线，或全部未检测到） |
| `0` | 正常行驶 |

**保护机制**：全部 8 路未检测到（冲出赛道）也返回 1，防止失控。

## 与转向控制的对接

```c
// control.c 中的调用方式
int ir_raw[8];
// ... 读取 8 路 GPIO → ir_raw[]
int error = calc_error(ir_raw);
if (is_stop(ir_raw)) {
    // 停车逻辑
}

// 正常巡线：偏差传入差速转向
steer_set(error, BASE_SPEED);
// 内部：左轮=base - steer_pid.Out, 右轮=base + steer_pid.Out
```

## 校准

红外传感器对不同地面反射率敏感，建议赛前：

1. 将车放在白色赛道上，确认所有传感器输出 0（白底）
2. 将车放在黑色边线上，确认对应传感器输出 1
3. 如灵敏度不足，调节 IR LED 亮度或传感器阈值电位器

## 故障排查

| 现象 | 可能原因 |
|------|----------|
| 始终全 0 或全 1 | IR LED 供电问题 / 传感器损坏 |
| 某路始终不触发 | 该路传感器故障或遮挡 |
| 左右不对称 | 安装偏斜 / 传感器灵敏度不一致 |
| 抖动严重 | 传感器离地距离太大 / 采样频率不足 |
