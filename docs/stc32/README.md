## 引脚分配

### 电机与编码器

| 功能 | 引脚 | 说明 |
|------|------|------|
| 电机1 方向 | IO_P74 | DIR_1 |
| 电机1 PWM | PWMB_CH2_P75 | PWM @ 17kHz |
| 编码器1 A相 | PWMA_ENCODER_CH1P_P60 | 脉冲 |
| 编码器1 B相 | PWMA_ENCODER_CH2P_P62 | 方向 |
| 电机2 方向 | IO_P76 | DIR_2 |
| 电机2 PWM | PWMB_CH4_P77 | PWM @ 17kHz |
| 编码器2 A相 | PWMC_ENCODER_CH1P_P40 | 脉冲 |
| 编码器2 B相 | PWMC_ENCODER_CH2P_P42 | 方向 |

### 红外循迹（八路）

| 传感器 | 引脚 | 权重 |
|--------|------|------|
| IR1 (最左) | IO_P00 | -7 |
| IR2 | IO_P01 | -5 |
| IR3 | IO_P02 | -3 |
| IR4 | IO_P03 | -1 |
| IR5 | IO_P04 | +1 |
| IR6 | IO_P05 | +3 |
| IR7 | IO_P06 | +5 |
| IR8 (最右) | IO_P07 | +7 |

> 引脚为预定义（代码中已注释），实际根据硬件接线调整。
